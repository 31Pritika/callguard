I. UDP Framing

Each packet carries a 4-byte sequence number, 8-byte timestamp, and 4-byte frame size so the receiver can detect drops without TCP retransmissions.

II. RFC 3550 Jitter

Interarrival jitter is smoothed continuously using the RTP standard formula J = J + (|D| - J)/16 to measure timing instability.

III. Slope Forecasting

Linear regression over the last 4 seconds projects delay and ITU-T MOS 5 seconds ahead, alerting you before the call crosses into failure.
